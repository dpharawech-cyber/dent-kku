# ทางไปทันตะ มข.

บอร์ดติดตามการเตรียมสอบ TCAS70 รอบ 3 กสพท (TPAT1 + A-Level) เข้าทันตแพทยศาสตร์ มข.

- ความคืบหน้าบันทึกอัตโนมัติในเบราว์เซอร์ของเครื่องที่ใช้ (localStorage)
- ปุ่ม "ส่งลิงก์ความคืบหน้า" สร้างลิงก์ที่มีข้อมูลทั้งหมดอยู่ในลิงก์ เปิดแล้วเป็นโหมดดูอย่างเดียว และใช้ย้ายข้อมูลไปเครื่องใหม่ได้
- ติดตั้งเป็นแอปบนมือถือได้ (Add to Home Screen) และเปิดได้แม้ออฟไลน์

เกณฑ์และวันที่อ้างอิงประกาศ กสพท ฉบับที่ 1 (10 ส.ค. 2569) และปฏิทิน ทปอ. ตรวจสอบกับประกาศทางการก่อนสมัครจริง
